## Policies

The [policy suite](policies/README.md) contains modular rules for acceptable use, data handling, model risk, third-party risk, prompt management, and change management.

Governance artifacts establish requirements. Assessments evaluate risk and readiness; testing guides describe assurance methods; checklists support decisions; templates preserve evidence; mappings connect the control model to external frameworks.
